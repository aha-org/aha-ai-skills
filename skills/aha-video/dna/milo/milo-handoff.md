# MILO — CLAUDE CODE HANDOFF

Read `Milo_Character_DNA_Remotion_Bible.docx` first.

The `Milo_Reference_Images/` folder contains the original visual references used to define the character.

## Critical rule

Milo is NOT one fixed silhouette. The references deliberately demonstrate a large deformation vocabulary.

Preserve Milo's identity while allowing:
- squash / stretch
- flattening
- widening
- leaning
- elongation
- temporary anatomy
- object interaction
- color changes
- eye-shape changes
- emotional transformations

The immutable identity anchors are:
1. organic Milo blob language
2. shallow M-like double-hump top
3. minimal black-eye language
4. matte tactile 2D rendering
5. natural/default green state
6. iconic soft contact shadow when grounded

Do not average the references into one pose.

Build a reusable Remotion Milo system rather than one-off animations. Prefer composable primitives for body deformation, eyes, color, emotion, shadow, grounding, and temporary anatomy.

Most important priority:
MILO CONSISTENCY > ANIMATION COMPLEXITY.

# Aha DNA: read this first

Every Aha skill carries this folder. It is how Aha looks, moves and sounds, written down from months of Manan's decisions. Read it before making anything, then read the skill's own instructions.

## Read in this order

1. `brand.md`: colours, type, logo, voice, and where colour is allowed.
2. `grain/GRAIN-GUIDE.md`: the grain gradient with hand-drawn lines (Aha's newest language). The code is `grain/grain.js` (web) and `grain/GrainShape.tsx` (React Native); `grain/grain-study.html` is the approved study.
3. `m3-expressive.md`: Material 3 Expressive shapes, corners and components, in Aha's colours.
4. `motion.md`: how things move (8 to 12 fps, eases, match cuts, focus entrances).
5. `milo/MILO.md`: Milo, Aha's character. Look, colours, eyes, voice, motion, and the three live versions (web, React Native, Remotion).
6. `checklist.md`: every correction Manan has made, as rules. Run it before showing anything.

## The short version

- **Less, but perfect.** One idea, one hero, generous space. Minimal never means empty.
- **Monochrome UI, colour in illustration.** Buttons, chips, inputs and selected states stay ink and cream. Colour lives in Milo, illustrations and grain pieces.
- **Grain gradients with lines** are Aha's signature for a person you're about to meet or a moment that matters. Solids stay the default everywhere else.
- **Material 3 Expressive** gives the shapes (cookie, sunny, flower, squircle) and the corner scale; grain and hand-drawn lines give them Aha's feel.
- **Stepped motion** at 8 to 12 fps feels hand-made. Eases, not springs, in product UI.
- **Milo** is curious, quietly playful, "he". He notices; he doesn't perform.
- **Plain words.** No em dashes, no emojis in UI copy, no jargon.

## When something here conflicts

Manan's latest decision wins, then the live Figma design system, then the current code, then this folder, then older notes. If you're unsure, ask Manan instead of guessing.
